# 🚀 InternSpark Task 2 - React Task Management SPA


A modern Single Page Application built using **React.js** that consumes a REST API and provides complete CRUD functionality for task management.


## 📌 Features

✅ Create Tasks  
✅ View All Tasks  
✅ View Single Task Details  
✅ Update Tasks  
✅ Delete Tasks  
✅ React Router Navigation  
✅ Axios API Integration  
✅ Loading State  
✅ Error Handling  
✅ Responsive UI  


## 🛠 Tech Stack

Frontend:

- React.js
- React Router DOM
- Axios
- JavaScript
- CSS


Backend:

- Node.js
- Express.js
- MongoDB
- Mongoose
